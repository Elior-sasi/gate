# Gate

הכרטיסים שלך, במקום אחד. Gate קורא מיילי כרטיסים מ-Gmail (קריאה בלבד) ומסדר כל הופעה, הצגה, סרט ומשחק בכרטיס אחד: תאריך ושעה, מקום וניווט, כיסאות, וקובץ הכרטיס / הברקוד לכניסה, עם הוספה ליומן ותזכורות.

- Next.js על Vercel, כניסה עם Google (NextAuth), ו-Gemini (אופציונלי) לקריאה מדויקת של פרטי האירוע.
- הכרטיסים נשמרים רק בטלפון. קובצי הכרטיס נפתחים ישירות מהמייל ולא נשמרים בשרת.

## משתני סביבה
ראה `.env.example`.

## תצוגה מקומית עם נתוני דוגמה
`GATE_DEMO=1 AUTH_SECRET=x npm run dev`
